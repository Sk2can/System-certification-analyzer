# SCA — System certification analyzer

**SCA** — приложение для автоматизации создания Word отчетов аппаратного обеспечения и установленного программного обеспечения компьютеров на основе TXT-отчётов.

Приложение формирует структурированные отчёты в формате Microsoft Word и позволяет настраивать классификацию программного обеспечения.

## Возможности

- **Инвентаризация оборудования** — сбор и оформление технических характеристик компьютеров.
- **Инвентаризация ПО** — формирование перечня установленных программ с группировкой по компьютерам.
- **Классификация программ** — распределение ПО по категориям, назначению и ключевым словам.
- **Настройка категорий** — добавление, редактирование и удаление правил классификации через консольное меню.
- **Генерация Word-отчётов** — формирование таблиц с настраиваемой структурой и оформлением.
- **Сборка приложения** — создание исполняемого файла для Windows с помощью PyInstaller.

## Технологии

- Python 3.12
- python-docx
- PyInstaller
- JSON для конфигурации

## Требования

- Windows
- Python 3.12 для запуска из исходного кода
- Зависимости из `requirements.txt`

Для запуска готового EXE устанавливать Python отдельно не требуется.

## Установка

Клонируйте репозиторий:

```bash
git clone <URL-репозитория>
cd SCA
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

Запустите приложение командой:

```powershell
.\.venv\Scripts\python.exe main.py
```

Следуйте инструкциям консольного меню.

## Конфигурация

Основные настройки находятся в каталоге `app/settings/`.

- `software_categories.json` — начальные правила классификации программного обеспечения.
- `software_table.json` — параметры оформления таблицы установленного ПО.

Пользовательские изменения категорий сохраняются в `%APPDATA%\SCA\software_categories.json`.

## Сборка EXE

Для сборки используется PyInstaller.

Запустите скрипт сборки из каталога `assembling` в соответствии с инструкциями проекта.

Готовый исполняемый файл создаётся в каталоге `assembling/dist/`.
